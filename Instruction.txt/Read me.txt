# 🛒 Growcer – Premium Grocery Website Landing Page

🚀 **Live Demo:** [View Live Preview](https://grocerywebsite-blush.vercel.app/)

A modern, high-performance, and fully responsive landing page designed explicitly for grocery stores, supermarkets, organic markets, and online delivery services. Built with pure vanilla technologies for maximum speed and seamless customization.

---

## 💎 Premium Features

* **Fully Responsive Layout:** Pixel-perfect display across mobile, tablet, and desktop viewports.
* **Modern Retail UI:** Vibrant, high-conversion design tailored specifically for food and retail industries.
* **E-Commerce Elements:** Pre-built interactive sections including categorized grids, promotional banners, and product badges (`Hot`, `New`, `Sale`, `Out of Stock`).
* **SEO & Speed Optimized:** Ultra-lightweight codebase with zero bloated frameworks, ensuring blazing-fast loading speeds.
* **Developer Friendly:** Clean markup and highly organized stylesheets make editing branding, text, and images effortless.

## 🚀 Quick Start / Installation

Follow these quick steps to host or modify the project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the root directory:**
   ```bash
   cd Grocery-Website
   ```

3. **Launch the site:**
   * Double-click `index.html` to run it directly in any browser.
   * *Alternative:* Right-click `index.html` and select **Open with Live Server** inside VS Code for instant hot-reloading.
