Growcer - Premium Grocery Website Template Documentation

Thank you for purchasing the Growcer Template! This comprehensive guide walks you through extracting files, running the site locally, configuring basic details, and completely customizing the template branding, design structure, content, and imagery assets to fit your supermarket business.

1. Package Archive Layout Structure

When you uncompress your primary template distribution package folder, you will find the following clean architecture assets:

├── images/ # Directory containing all optimized grocery item graphics & UI icons
├── index.html # Primary semantic markup core structure for the storefront
├── style.css # Clean, modular global stylesheet controlling all visual layout designs
├── script.js # Core JavaScript framework handling smooth scroll and dynamic UI behaviors
└── documentation.html # This comprehensive installation & customization instruction manual

2. Quick Installation & Launch Guide

Follow these absolute steps to get your template project up and running locally on your computer:

  1. Extract Download Archive: Right-click the downloaded growcer-grocery-template.zip archive and select Extract All... to create a standard, uncompressed file directory.
  2. Opening the Website Files:
    • To view the live running template, navigate inside the folder and double-click the index.html file. It will instantly launch inside any modern internet browser (Google Chrome, Safari, Mozilla Firefox, Microsoft Edge).
    • To customize code structures, download a free source code workspace code editor such as Visual Studio Code or Sublime Text, open the program, click File ➔ Open Folder, and select your extracted directory.
  3. Local Git Deployment (Optional): If you prefer to track revisions via Github, use this complete verified clone path inside your terminal shell core layout execution console:
git clone https://github.com
cd Grocery-Website

3. Template Customization Manual

Every element of the Growcer frontend web platform can be easily configured by opening up the project files inside your code editor workspace.

A. Changing the Store Branding & Logo

Open index.html and search for the logo navigation block near line 10-30. Look for the image source link tag:

<!-- Navigation Logo Block -->
<img src="images/logo.png" alt="Growcer Logo">

To update it: Simply place your new brand emblem file directly into your local images/ folder directory and change the name within the src="" text quotation parameter markup configuration block.

B. Editing Category Listings & Grid Labels

Open index.html and locate the section starting with the comment <!-- SHOP BY CATEGORY -->. To update the category text content card layout labels, simply overwrite the text within the heading tags:

<!-- Change Category Title Here -->
<h2>Fruits</h2>
<p>22 Items</p>

C. Updating Product Cards, Pricing, & Sale Badges

Locate the product layout section labeled <!-- Farm Fresh Products Grid --> inside index.html. Each food item is enclosed inside a clean card block component wrapper. You can change product content text, pricing arrays, or discount tags easily:

<!-- Example Product Card Customization structure -->
<span class="badge">10% Off</span> <!-- Change sale status tag here -->
<h3>Red Capsicum</h3> <!-- Edit product catalog text name here -->
<span class="price">$20.00</span> <!-- Adjust retail pricing value here -->

D. Substituting Product Images

All stock photography is organized directly inside the local images/ directory folder. To swap food items out with your custom grocery inventory assets, overwrite the existing file image names references listed in your elements:

<img src="images/red-capsicum.png" alt="Red Capsicum Image Layout">

E. Adjusting Theme Colors & Style Typography

Open up the style.css file. All core background brand layout coloring matrices, header font sizing properties, structural dimensions variables, and UI button layouts are configured here.

  • To modify global button or background accents, find the color variables or search for standard properties like background-color: #004d43; or matching color hex values and replace them with your custom company hexadecimal branding pallet parameters.
  • To adjust layout presentation margins or card scaling blocks elements parameters, alter the CSS grid flex spacing configurations properties values listed in the respective classes.
💡 Pro-Tip for Hot Reloading: For a faster editing experience, install the Live Server extension inside Visual Studio Code. This will instantly refresh your open web browser preview window every single time you hit save on your code edits!
